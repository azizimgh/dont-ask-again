# Security

**Never paste a real secret into an issue, pull request or discussion.** Replace the value with a
fake one of the same shape. If you already did, rotate that credential: deleting the comment is
not enough.

To report a vulnerability in dont-ask-again itself (for example, a way to make it print an
unmasked secret or write a file outside the repo), use GitHub's private
[security advisory](https://github.com/azizimgh/dont-ask-again/security/advisories/new) form
rather than a public issue.
